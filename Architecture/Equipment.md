# Иерархия классов и их полей и функций

## Класс `Material`

| Поле/Функция          | Тип/Возвращаемый тип | Описание                                      |
|-----------------------|----------------------|-----------------------------------------------|
| `name_`               | `std::string`        | Имя материала                                 |
| `armorMultiple_`      | `double`             | Множитель брони                               |
| `GetName()`           | `std::string`        | Возвращает имя материала                      |
| `GetArmorMultiple()`  | `double`             | Возвращает множитель брони                    |
| `SetName(std::string name)` | `void` | Устанавливает имя материала              |
| `SetArmorMultiple(double armorMultiple)` | `void` | Устанавливает множитель брони |

## Классы, наследующие от `Material`

| Класс       | Описание                                      |
|-------------|-----------------------------------------------|
| `Decorative` | Материал с декоративным множителем брони      |
| `Dimond`    | Материал с алмазным множителем брони          |
| `Gold`      | Материал с золотым множителем брони           |
| `Iron`      | Материал с железным множителем брони          |
| `NoMaterial`| Материал без множителя брони                  |

## Класс `Equip`

| Поле/Функция          | Тип/Возвращаемый тип | Описание                                      |
|-----------------------|----------------------|-----------------------------------------------|
| `armor_`              | `double`             | Значение брони                                |
| `material_`           | `std::shared_ptr<Material>` | Указатель на материал              |
| `name_`               | `std::string`        | Имя экипировки                               |
| `GetArmor()`          | `double`             | Возвращает значение брони                     |
| `GetMaterial()`       | `std::shared_ptr<Material>` | Возвращает указатель на материал |
| `GetName()`           | `std::string`        | Возвращает имя экипировки                     |
| `SetArmor(double armor)` | `void` | Устанавливает значение брони           |
| `SetMaterial(std::shared_ptr<Material> material)` | `void` | Устанавливает материал |
| `SetName(std::string name)` | `void` | Устанавливает имя экипировки           |

## Классы, наследующие от `Equip`

| Класс       | Описание                                      |
|-------------|-----------------------------------------------|
| `Helmet`    | Шлем с определенным значением брони           |
| `Chestplate`| Нагрудник с определенным значением брони      |
| `Boots`     | Ботинки с определенным значением брони        |

## Класс `MyEquip`

| Поле/Функция          | Тип/Возвращаемый тип | Описание                                      |
|-----------------------|----------------------|-----------------------------------------------|
| `armorSet`            | `std::vector<std::shared_ptr<Equip>>` | Набор экипировки                |
| `MyEquip()`           | Конструктор          | Конструктор класса `MyEquip`                  |
| `SetHelmet(std::shared_ptr<Equip> helmet)` | `void` | Устанавливает шлем               |
| `SetChestplate(std::shared_ptr<Equip> chestplate)` | `void` | Устанавливает нагрудник |
| `SetBoots(std::shared_ptr<Equip> boots)` | `void` | Устанавливает ботинки             |
| `TotalArmor()`        | `double`             | Возвращает общую броню                       |

| Поле/Функция          | Тип/Возвращаемый тип | Описание                                      |

| `Reset()`             | `void`               | Сбрасывает билдер                             |

| `SetMaterial(std::shared_ptr<Material> material)` | `void` | Устанавливает материал |
| `SetName(std::string name)` | `void` | Устанавливает имя экипировки           |
| `GetResult()`         | `std::shared_ptr<Equip>` | Возвращает результат билдера       |
