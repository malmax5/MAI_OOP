# Иерархия классов и их полей и функций

## Класс `Game`

| Поле/Функция          | Тип/Возвращаемый тип | Описание                                      |
|-----------------------|----------------------|-----------------------------------------------|
| `Game()`              | Конструктор          | Конструктор класса `Game`.                    |
| `Start()`             | `void`               | Запускает игру.                               |
| `Update()`            | `void`               | Обновляет состояние игры.                     |
| `End()`               | `void`               | Завершает игру.                               |
| `AddNPC(std::shared_ptr<NPC> npc)` | `void` | Добавляет NPC в игру.                   |
| `RemoveNPC(int npcId)` | `void`               | Удаляет NPC из игры по его ID.                |
| `RemoveDeads()`       | `void`               | Удаляет мертвых NPC из игры.                  |
| `PrintNPC()`          | `void`               | Выводит информацию о NPC в игре.              |
| `Attach(std::shared_ptr<Observer> observer)` | `void` | Присоединяет наблюдателя к игре.       |
| `Detach(std::shared_ptr<Observer> observer)` | `void` | Отсоединяет наблюдателя от игры.       |
| `Notify(const std::string& event)` | `void` | Уведомляет всех наблюдателей о событии. |
| `npcInGame_`          | `std::vector<std::shared_ptr<NPC>>` | Список NPC в игре. |
| `observers`           | `std::vector<std::shared_ptr<Observer>>` | Список наблюдателей. |
| `getInfoVisitor`      | `std::shared_ptr<Visitor>` | Посетитель для получения информации. |
| `gameThread`          | `std::thread`        | Поток игры.                                   |
| `shouldStop_`         | `std::atomic<bool>`  | Флаг для остановки игры.                      |
| `isThreadRunning`     | `bool`               | Флаг, указывающий, запущен ли поток игры.     |

## Класс `EnemyMask`

| Поле/Функция          | Тип/Возвращаемый тип | Описание                                      |
|-----------------------|----------------------|-----------------------------------------------|
| `EnemyMask`           | `static std::map<NPCId, std::set<NPCId>>` | Статический атрибут, содержащий маску врагов для каждого типа NPC. |
| `InMaskAttack(NPCId attacker, NPCId target)` | `bool` | Проверяет, может ли атакующий NPC атаковать цель на основе маски врагов. |
